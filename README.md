# PMP Study Hub

My personal study site for the PMP exam (target: December 2027), aligned to the PMI PMP Examination Content Outline that took effect in July 2026.

**Open it:** https://denth-jd.github.io/pmp-study-hub/

- `js/content.js`: study modules, roadmap, mindset scenarios, flashcards, resources
- `js/quiz.js`: practice question sets
- `js/app.js`: app logic. Plain HTML/CSS/JS with no build step.

The notes are my own summaries. PMI, PMP and PMBOK are registered marks of the Project Management Institute, Inc. This site is not affiliated with PMI.
